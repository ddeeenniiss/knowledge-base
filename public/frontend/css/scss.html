SCSS (Sassy CSS)

SCSS ist eine Erweiterung von CSS, die zusätzliche Funktionen wie Variablen, Verschachtelung und Mixins bereitstellt.

Maps

Maps sind eine Datenstruktur in SCSS, die Schlüssel-Wert-Paare speichert und verwendet werden kann, um komplexe Daten zu organisieren

        $colors: (
            'red': #ff2756,
            'teal': #449fa9,
            ..
        );

Das ist jetzt die Map 'colors', die verwendet werden kann, um Farben in SCSS zu verwalten.

CSS Variablen generieren

SCSS Maps können verwendet werden, um CSS Variablen dynamisch zu generieren. Dafür wird die Map durchlaufen und für jede Farbe eine CSS Variable erstellt. 

        :root{
            @each $key, $value in $colors{
                --color-#{$key}: #{$value};
            }
        }

:root sorgt dafür, dass alle Klassen global verfügbar sind. @each ist hier die SCSS-Iterationsschleife über alle Farben. #{$key} ist die String-Interpolation.

Utility Classes erstellen

        @each $key, $value in $colors{
            .text-#{$key}{
                color: #{$value};
            }
            .bg-#{$key}{
                background-color: #{$value};
            }
        }

SCSS Dateien/ Module importieren

Mit @use werden SCSS Module in andere SCSS Dateien importiert. Die Module werden in separate Dateien organisiert, um die Wiederverwendbarkeit und Struktur der Stylesheets zu verbessern.

Eingebaute SCSS Module

sass:string

Funktionen für Strings, zB string.length("Hallo") oder string.insert()

sass:list

Funktionen für Listen, zB list.join($a, $b), list.nth($list, 2)

        @use "sass:list';
        $colors: red, blue, green;
        $second-color: list.nth($colors, 2); //blue

@mixin Vorlage

Ein @mixin ist eine wiederverwendbare SCSS-Funktion, die in anderen SCSS-Dateien aufgerufen werden kann.

        @mixin fancy-border($color){
            border: 2px solid $color;
        }

        .button{
            @include fancy-border(red);
        }

Beispiel als _breakpoints.scss

        @use 'sass:map';

        $breakpoints: (
            'md': '768px',
            'lg': '1024px',
        );

        @mixin breakpoint-up($size){
            @if not map.get($breakpoints, $size){ //1
                @warn "Breakpoint \"#{$size}\" not available.";
            }

            $breakpoint-value: map.get($breakpoints, $size); //2

            @media screen and (min-width: $breakpoint-value){ //3
                @content;
            }
        }

'sass:map' bringt Funktionen für Map Operationen

1. prüft, ob der angegebene Breakpoint ($size) in der Map $breakpoints existiert. Wenn nicht, gibt Sass eine Warnung

2. Holt den Pixelwert für den breakpoint

3. Erstellt eine Media Query
