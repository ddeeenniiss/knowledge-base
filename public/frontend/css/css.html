CSS (Cascading Style Sheets)

CSS ist für das Styling von HTML Elementen verantwortlich.

CSS wird vorzugsweise in externen Stylesheets geladen, kann aber ebenso inline im HTML Dokument als style Tag oder inline direkt in den HTML Elementen als style Attribut verwendet werden.

CSS Syntax

Kommentare werden einfach mit // oder /* */ gekennzeichnet.

Kategorien der HTML Selektoren

Universelle Selektor

Der * Selektor wählt alle Elemente auf der Seite aus.

Gruppierungs Selektor

Gruppiert mehrere Selektoren mit einem Komma (,) zusammen.

Einfache Selektoren

Selektoren anhand von Klassen (.class), ID (#id) oder Selektoren auswählen

Kombinator Selektoren

Nachfahrenkombinator

wählt alle Elemente aus, die Nachfahren eines bestimmten Elements sind. 

      div p {
        color: black;
      }

Kindkombinator

wählt alle direkten Kind-Elemente eines Elements aus.

      div > p {
      color: black;
    }

Nächster Geschwisterkombinator

wählt alle Elemente aus, die direkt nach einem bestimmten Element folgen.

      div + p {
        color: black;
      }

Subsequent Geschwisterkombinator

wählt alle Geschwisterelemente von bestimmten Elementen aus. zB alle p Elemente, die direkte Geschwister von div Elementen sind und div als Elternelement haben. 

      div ~ p {
        color: black;
      }

Pseudoklassen Selektoren

Selektoren, die auf speziellen Zuständen wie hover, focus, visited usw. basieren. Pseudoklassen werden immer durch einen Doppelpunkt (:) gefolgt von einem Namen definiert.

Interaktive Pseudoklassen

  1. :hover - wenn der Mauszeiger über dem Element schwebt
  2. :focus - wenn das Element fokussiert ist
  3. :active - wenn ein Element aktiviert wird
  4. :link - wenn ein Link unbesucht ist
  5. :visited - wenn ein Link besucht wurde

Strukturelle Pseudoklassen

  1. :first-child - wählt das erste Kind-Element eines Elternelements aus
  2. :last-child - wählt das letzte Kind-Element eines Elternelements aus
  3. :nth-child(n) - wählt das n-te Kind-Element eines Elternelements aus
  4. :lang() - wählt Elemente mit einer bestimmten Sprache aus

CSS Pseudoelemente

Pseudoelemente werden durch (::) gekennzeichnet.

Text Pseudoelemente

formatieren bestimmte Teile des Textinhalts

  1. ::first-line - formatiert die erste Textzeile
  2. ::first-letter - formatiert den ersten Buchstaben des Textes

Inhalts-Pseudoelemente

fügen generierten Inhalt vor oder nach dem normalen Inhalt ein oder formatieren diesen.

  1. ::before - fügt Inhalt vor dem normalen Inhalt ein
  2. ::after - fügt Inhalt nach dem normalen Inhalt ein
  3. ::marker - formatiert Marker von Listenelementen
  4. ::selection - formatiert ausgewählten Text
  5. ::backdrop - formatiert den Hintergrund des Elements zB bei lightbox

Attributsselektoren

Lassen sich auf Elemente anwenden, die ein bestimmtes Attribut besitzen. Im folgenden Beispiel werden alle a Elemente ausgewählt, die das Attribut target mit dem Wert "_blank" haben. 

      a[target="_blank"]{
        color: black;
      }

background

background-color

Setzt die Hintergrundfarbe eines Elements.

background-image

Setzt ein Hintergrundbild für ein Element.

background-repeat

legt fest, wie sich das Hintergrundbild wiederholt. Mögliche Werte: repeat, no-repeat, repeat-x, repeat-y

background-attachment

legt fest, ob das Hintergrundbild mit dem Scrollen des Elements mitscrollt oder nicht. values: scroll, fixed, local

background-position

legt die Position des Hintergrundbildes fest. values: left, right, center, top, bottom

background

background: [color] [image] [position] / [size] [repeat] [attachment] [origin] [clip];

Kombiniert alle background-Eigenschaften in einer Regel. Wird nur verwendet, wenn alles definiert werden soll, da background alles zurücksetzt, was nicht explizit definiert wird.

box-sizing: border-box;

Content + Padding + Border sind gemeinsam die width

content-box:

Nur Inhalt ist width, padding und border zählen exklusiv zusätzlich

border-style: dotted solid double dashed

gibt jeder Seite einen anderen Stil

margin - Außenabstand

setzt den Außenabstand eines Elements in px, em, rem, %, auto (vom Browser berechnet) oder inherit (vom übergeordneten Element übernommen).

Die Kurzform aller margin Eigenschaften ist: margin: top right bottom left;

margin-inline steht für horizontalen Außenabstand und margin-block für vertikalen Außenabstand.

margin-collapse

Wenn zwei Elemente mit Außenabständen übereinander liegen, werden diese zusammengefasst. Der Gesamt Außenabstand ist dann der größere der beiden vertikalen Außenabstände. Genauso wenn das child eines parents einen Außenabstand hat, wird dieser mit dem Außenabstand des parents zusammengefasst.

position: definiert die Positionierung eines Elements

    
Dafür gibt es die folgenden 5 Hauptwerte: 

    
    
      
  • static: Standardwert, Element wird normal im Fluss des Dokuments positioniert. Verschieben funktioniert hier nicht
    • 
      
  • relative: Element wird relativ zu seiner ursprünglichen Position verschoben zB mit top, right, bottom, left, z-index
    • 
      
  • absolute: Element wird absolut positioniert, relativ zu seinem nächsten positionierten Elternelement. Dieses Element wird aus dem Dokumentenfluss entfernt, andere Elemente
        verhalten sich so, als wäre es nicht da.
    • 
      
  • fixed: Element bleibt an einer festen Position im Viewport, unabhängig von Scrollen. Positionierugen sind relativ zum Viewport. Elemente sind nicht mehr Teil des Dokumentenflusses.
    • 
      
  • sticky: Element verhält sich wie fixed, sobald es den Viewport verlässt. Bei der Deklaration ist es wie position: relative, beim scrollen wie position: fixed. Element bleibt Teil des Dokumentenflusses.
    • 
      
    

    
top, right, bottom, left legen jeweils den margin des Elements fest. Eine Abkürzung dafür wäre auch
      inset: top right bottom left;
    

    
    
sticky vs fixed

    
fixed: Element bleibt an einer festen Position im Viewport, unabhängig von Scrollen.

    
sticky: Element verhält sich wie fixed, sobald es den Viewport verlässt.

    
translate:

    
Um ein Element mittig zu positionieren, kann man position: relative; und translate: -50% -50%; verwenden.

Farben

    
rgba

    
rgba steht für red, green, blue, alpha (Transparen).
      Werte für r, g, b liegen zwischen 0 und 255, alpha liegt zwischen 0 (vollständig transparent) und 1 (garnicht transparent).
    

    
hex Farben #rrggbb

    
rr, gg, bb sind hexadezimale Werte (0-9, A-F) für Rot, Grün und Blau.

    
hsl

    
hsl steht für hue, saturation, lightness (Farbton, Sättigung, Helligkeit).

    
Der Farbton liegt zwischen 0 und 360 Grad. 0 ist Rot, 120 ist Grün, 240 ist Blau. Bei Sättigung ist 0%
      ein Grauton, 100% bedeutet volle Sättigung. Bei Helligkeit ist 0% schwarz und 100% weiß.

border: 'Pixelgröße' 'Stil' 'Farbe'; Der Stil kann z.B. solid, dotted, dashed, ridge sein.

float Eigenschaft

    
mit float können Elemente links oder rechts vom Inhalt positioniert werden.

    
      float: left;
    

    
positioniert ein Element links vom Inhalt.

    
display: inline-block

    
display: inline-block setzt ein Element auf inline und erlaubt es, width und height zu setzen. Die Eigenschaft wird
      dabei dem wrapper Element zugewiesen. Die child Elemente werden entsprechend der width und height des wrappers angeordnet.
      Sie können selbst width und height haben.
    

    
height - Höhe

    
Kann auto sein, also vom Browser berechnet. Ebenso initial ist möglich, was die Höhe auf ihren Standardwert zurücksetzt.
      Ebenso inherit, was die Höhe vom übergeordneten Element übernimmt.
    

    
width Eigenschaft

    
Mit width=100% werden Bilder responsive skaliert und auf die Breite des Elterncontainers skaliert. Bei width = auto; berechnet der Browser
      die Breite des aktuellen Elements abhängig vom Layout Kontext (also display-Typ, welches Layout).
    

    
max-width Eigenschaft

    
Mit max-width=100% wird das Element maximal auf die Breite des Elterncontainers begrenzt, kann sich bei Bedarf allerdings verkleinern.

    
picture Element

    
Das picture Element erlaubt es, verschiedene Bilder für verschiedene Bildschirmgrößen oder -auflösungen zu verwenden.
      Es wird mit source Elementen verwendet, die jeweils ein media Attribut für die Bildschirmgröße und ein srcset Attribut für die Bildquelle haben. Das img Element dient als Fallback, falls keine der Bedingungen der source Elemente erfüllt ist.
    

    
outline Eigenschaft

    
Die outline Eigenschaft erzeugt eine Linie um ein Element herum, die nicht Teil des Boxmodells ist und somit den Abstand des Elements nicht beeinflusst. Es wird meißt für focus styles verwendet.

    
    
      
  • outline-style: gibt den Stil der Outline an (none, dotted, dashed, solid)
    • 
      
  • outline-color: gibt die Farbe an
    • 
      
  • outline-width: gibt die Breite der Outline an
    • 
      
  • outline-offset: gibt den Abstand der Outline zum Element an
    • 
      
  • outline: width style color ist die Kurzschreibweise
    •

steuert die Groß und Kleinschreibung von Text
