Häufige Fehler bei Safari:

Flexbox + Overflow: display: flex; overflow: auto; Container wird zu groß / Scroll funktioniert nicht

Lösung: min-width: 0; min-height: 0;

Mobile Safari berechnet vh oft falsch

Lösung: height: 100dvh;

SVGs können in Safari falsche Größen haben

Lösung: flex-shrink: 0; oder width: 100%; height: auto;

line-height in rem angeben. Sollte immer als Faktor angegeben werden, da safari anders rendert. Dieser berechnet sich durch Lineheight in px / Schriftgröße. zB 55 / 50 = 1.1

Bei Safari und Flexbox immer min-width: 0; und width: ..px; und eine max-width begrenzung. Oder direkt flex 0 0 width;
