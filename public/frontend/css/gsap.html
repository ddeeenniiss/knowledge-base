GSAP (GreenSock Animation Platform)

GSAP ist eine leistungsstarke JavaScript-Bibliothek für anspruchsvolle Animationen im Web.

Verwendung in Projekten

Einfach einbinden per script

Tweening - in betweening

Ein Tween ist die Animation von einem Startwert zu einem Endwert über eine bestimmte Zeit. Zwischenzustände werden automatisch berechnet. Getweent werden können x, y, opacity, scale, rotation (in Grad), color, svg Attribute, scroll Positionen, Canvas Werte, JavaScript Objekte etc. 

      gsap.to(".box", {
        x: 300,     //in Pixel nach rechts
        xPercent: 900, // 900% der eigenen Breite nach rechts, also bei 50px 900% von 50px = 450px
        yPercent: 100, // 100% der eigenen Höhe nach unten
        scale: 2, //verdoppelt die Größe, scaleX und scaleY gibts auch
        opacity: 0.5, // halbtransparent
        transformOrigin: "100% 0%", // Ursprung der Transformation ist die obere rechte Ecke
        duration: 1 //in Sekunden
        rotationX: 360, //Drehung um die X-Achse
      });

Start ist die aktuelle Position und das Ende ist bei x=300. Die Dauer ist insgesamt bei 1 Sekunde. GSAP berechnet alle Zwischenwerte automatisch.

to()

Die to() Methode animiert vom aktuellen Zustand zu einem Endwert.

from()

Die from() Methode animiert von einem Startwert zum aktuellen Zustand.

fromTo()

Start und Endwert werden explizit angegeben.

onUpdate()

Callback-Funktion, die bei jedem Frame der Animation aufgerufen wird, an dem sich der animierte Wert ändert. 

      const progress = document.querySelector('.progress'); //Fortschrittsleiste
      const label = document.querySelector('.label'); //Label für Prozentanzeige

      slider.addEventListener('input', function() { //bei jeder Änderung des Sliders
        gsap.to(progress, {
          width: `${this.value}%`, //aktueller Slider Wert in Prozent
          duration: 0.2,
          onUpdate: function(){
            label.textContent = `${Math.round(gsap.getProperty(progress, 'width'))}%`; //liest aktuelle animierte Breite aus
          }
        });
      });

yoyo, repeat, onComplete Eigenschaft

Die yoyo Eigenschaft sorgt dafür, dass die Animation nochmal rückwärts abgespielt wird.

      let box = document.querySelector('.box');

      gsap.to(box, {
        duration: 1,
        x: 200,
        repeat: 2, //bei -1 unendlich oft wiederholen
        yoyo: true, //nach jedem Durchlauf rückwärts abspielen
        delay: 1, //1 Sekunde Verzögerung vor Start
        onComplete: () => { alert('Animation finished!')}
      })
