GSAP (GreenSock Animation Platform)

GSAP ist eine leistungsstarke JavaScript-Bibliothek für anspruchsvolle Animationen im Web.

Verwendung in Projekten

Einfach einbinden per script

Tweening - in betweening

Ein Tween ist die Animation von einem Startwert zu einem Endwert über eine bestimmte Zeit. Zwischenzustände werden automatisch berechnet. Getweent werden können x, y, opacity, scale, rotation (in Grad), color, svg Attribute, scroll Positionen, Canvas Werte, JavaScript Objekte etc. 

      gsap.to(".box", {
        x: 300,     //in Pixel nach rechts
        xPercent: 900, // 900% der eigenen Breite nach rechts, also bei 50px 900% von 50px = 450px
        yPercent: 100, // 100% der eigenen Höhe nach unten
        scale: 2, //verdoppelt die Größe, scaleX und scaleY gibts auch
        opacity: 0.5, // halbtransparent
        transformOrigin: "100% 0%", // Ursprung der Transformation ist die obere rechte Ecke
        duration: 1 //in Sekunden
        rotationX: 360, //Drehung um die X-Achse
      });

gsap.to ist die Methode, ".box" ist das target und x: 200 ist key-value

Start ist die aktuelle Position und das Ende ist bei x=300. Die Dauer ist insgesamt bei 1 Sekunde. GSAP berechnet alle Zwischenwerte automatisch. Es gibt folgende 4 Methoden:

to()

Die to() Methode animiert vom aktuellen Zustand zu einem Endwert.

from()

Die from() Methode animiert von einem Startwert zum aktuellen Zustand.

fromTo()

Start und Endwert werden explizit angegeben.

set()

setzt Eigenschaften /keine Animation.

onUpdate()

Callback-Funktion, die bei jedem Frame der Animation aufgerufen wird, an dem sich der animierte Wert ändert. 

      const progress = document.querySelector('.progress'); //Fortschrittsleiste
      const label = document.querySelector('.label'); //Label für Prozentanzeige

      slider.addEventListener('input', function() { //bei jeder Änderung des Sliders
        gsap.to(progress, {
          width: `${this.value}%`, //aktueller Slider Wert in Prozent
          duration: 0.2,
          onUpdate: function(){
            label.textContent = `${Math.round(gsap.getProperty(progress, 'width'))}%`; //liest aktuelle animierte Breite aus
          }
        });
      });

yoyo, repeat, onComplete Eigenschaft

Die yoyo Eigenschaft sorgt dafür, dass die Animation nochmal rückwärts abgespielt wird. 

      let box = document.querySelector('.box');

      gsap.to(box, {
        duration: 1,
        x: 200,
        repeat: 2, //bei -1 unendlich oft wiederholen
        yoyo: true, //nach jedem Durchlauf rückwärts abspielen
        delay: 1, //1 Sekunde Verzögerung vor Start
        onComplete: () => { alert('Animation finished!')}
      })

Generelle Tipps:

Am besten transform und opacity bevorzugen vor top, left, margin. Das bringt smoothere Animationen. Für transform gibt es eine shorthand: 

      transform: rotate(360deg) translateX(10px) translateY(50%);

kann einfach folgendes genutzt werden:

{ rotation: 360, x: 10, yPercent: 50 }

stagger Eigenschaft

Mit der stagger Eigenschaft können mehrere Elemente zeitversetzt animiert werden.

Es können mehrere Eigenschaften als Objekt mitgegeben werden, wie zB each: 0.1 für die Verzögerung und from: start für zB das beginnen der Elemente mit unterschiedlicher Reihenfolge der Verzögerung.

amount: 0.5 beschreibt den Zeitraum der Animation. Diese Zeit geteilt durch die Anzahl der Gesamtelemente ergibt den Zwischenwert für die Verzögerung pro Element.

Timelines

      let tl = gsap.timeline()

      tl.to("green", { x: 600, duration: 2 });
      tl.to("purple", { x: 600, duration: 1 });
      tl.to("orange", { x: 600, duration: 1 });

Mit delay auf einem Element kann es verzögert werden.

position Parameter

      let tl = gsap.timeline()

      // start at exactly 1 second into the timeline (absolute)
      tl.to(".green", { x: 600, duration: 2 }, 1);

      // insert at the start of the previous animation
      tl.to(".purple", { x: 600, duration: 1 }, "<");

      // insert 1 second after the end of the timeline (a gap)
      tl.to(".orange", { x: 600, duration: 1 }, "+=1");

Timeline defaults:

Mit defaults können Eigenschaften für alle Animationen innerhalb einer Timeline einmal festgelegt werden und müssen dann nicht mehr wiederholt werden. Das ist besser als sie bei jedem to(), from() oder fromTo() zu wiederholen. defaults können jederzeit einfach überschrieben werden. 

	var tl = gsap.timeline({defaults: {duration: 1}});

	//no more repetition of duration: 1!
	tl.to(".green", {x: 200})
  		.to(".purple", {x: 200, scale: 0.2})
  		.to(".orange", {x: 200, scale: 2, y: 20});

Timeline Nesting

Durch Timeline Nesting können mehrere Timelines als Bausteine in einer Haupttimeline verwendet werden. 

	function createHeroTimeline() {
  		return gsap.timeline()
    		.from(".headline", { y: 100, opacity: 0 })
    		.from(".subtitle", { opacity: 0 });
	}

	function createCardsTimeline() {
  		return gsap.timeline()
    		.from(".card", {
      			y: 50,
      			opacity: 0,
      			stagger: 0.2
    		});
	}

	const master = gsap.timeline({
		paused: true, // do not start when page is loaded
	});

	master
  		.add(createHeroTimeline())
  		.add(createCardsTimeline(), "+=2"); // with a gap of 2 seconds

	master.play();

GSAP Control Methods

	// store the tween or timeline in a variable
	let tween = gsap.to("#logo", {duration: 1, x: 100});

	//pause
	tween.pause();

	//resume (honors direction - reversed or not)
	tween.resume();

	//reverse (always goes back towards the beginning)
	tween.reverse();

	//jump to exactly 0.5 seconds into the tween
	tween.seek(0.5);

	//jump to exacty 1/4th into the tween 's progress:
	tween.progress(0.25);

	//make the tween go half-speed
	tween.timeScale(0.5);

	//make the tween go double-speed
	tween.timeScale(2);

	//immediately kill the tween and make it eligible for garbage collection
	tween.kill();

	// You can even chain control methods
	// Play the timeline at double speed - in reverse.
	tween.timeScale(2).reverse();

GSAP Callbacks

Callbacks können verwendet werden, um zu bestimmten Zuständen auf eine Animation zuzugreifen.

onComplete: invoked when the animation has completed.

onStart: invoked when the animation begins

onUpdate: invoked every time the animation updates (on every frame while the animation is active).

onRepeat: invoked each time the animation repeats.

onReverseComplete: invoked when the animation has reached its beginning again when reversed. 

	gsap.to(".class", {
  		duration: 1, 
  		x: 100, 
  		// arrow functions are handy for concise callbacks
  		onComplete: () => console.log("the tween is complete")
	});

Häufige Fehler:

  1. Zuerst sollte alles ohne Animation funktionieren. Erst dann Animation hinzufügen. Oftmals ist nicht die Animation oder der ScrollTrigger das Problem.
  2. Vermeide ScrollTrigger auf nested Timelines. Da sowohl Timeline als auch Scrolltrigger beide Playhead bestimmen und dies zu Konflikten führt.
  3. scroll-behavior: smooth kann Ungenauigkeiten der start/end Punkte hervorrufen beim resizen des Bildschirms
  4. Besser .to() und .from() verwenden, anstatt .fromTo() da diese dynamischer sind.
