JS - JavaScript

JavaScript ist eine Scriptsprache, nicht typisiert (dynamisch typisiert) und wird interpretiert. Es ist objektorientiert, aber ohne Klassen.

Variablen

Variablen sind Namen für den Ort im Speicher

Kommentare

In JavaScript funktionieren Kommentare durch einen Zeilenkommentar // oder /**/ für mehrzeilige Kommentare.

Datentypen

JavaScript verwendet intern ganze Zahlen, Gleitkommazahlen, Zeichenketten, Boolesche Werte, Objekte

Zeichenketten

Sicherheit

JavaScript ist aktiver Code, der im Browser ausgeführt wird. Das ist potentielles Sicherheitsrisiko. Das Grundprinzip der Sicherheit ist Sandbox (eingesperrt ohne Zugriff auf Dateisystem). Jeder Browser führt JS schon in einer Sandbox aus. Weiterhin ist ein Container/VM wie Docker eine sichere Methode.

JavaScript kann PopUps öffnen womit man Nutzer fluten kann. Daher wird window.open von Popup Blocker blockiert.

XSS - Cross Site Scripting

Einbinden von schädlichem JavaScript in eine andere, vertrauenswürdige Seite. zB über Formulareingaben oder HTTP Parameter.

Um das vorzubeugen muss verhindert werden, dass eingegebene Daten Skripte enthalten können.

IntersectionObserver

Der IntersectionObserver ermöglicht es, das Sichtbarkeitsverhalten von Elementen im Viewport zu überwachen. Dies ist besonders nützlich für Lazy Loading von Bildern, Infinite Scrolling oder das Auslösen von Animationen, wenn ein Element in den sichtbaren Bereich des Bildschirms gelangt.

Beispiel: Module bei straehle, die in den Bildschirm einfaden

  
    document.addEventListener('DOMContentLoaded', () => {
  const elements = document.querySelectorAll<HTMLElement>('.animate-on-scroll');

  const observer = new IntersectionObserver(
    (entries, obs) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-visible');
          obs.unobserve(entry.target); // nur einmal animieren
        }
      });
    },
    {
      threshold: 0.1 // 10% sichtbar = Animation starten
    }
  );

  elements.forEach(el => observer.observe(el));
});

DOMContentLoaded

Das DOMContentLoaded-Ereignis tritt auf, sobald der HTML-Dokument-Inhalt vollständig geladen und geparst wurde, ohne auf externe Ressourcen wie Bilder oder Skripte zu warten. Es ist nützlich, um sicherzustellen, dass das DOM (zB. Buttons, Listen, Nav Elemente) bereit ist, bevor JavaScript-Operationen ausgeführt werden. 

document.addEventListener('DOMContentLoaded', () => {});

DOM (Document Object Model)

ist eine Schnittstelle, um den Inhalt, die Struktur und das Styling eines HTML-Dokuments dynamisch zu verändern. Es repräsentiert das Dokument als Baumstruktur, wobei jedes Element im Baum ein Objekt ist, das über JavaScript manipuliert werden kann. Der Einstiegspunkt dafür ist .document

Es gibt dabei drei wirkliche Wurzeln:

  • window: aktuelles Browserfenster, globales Objekt im Browser. Darauf liegen zB document, localStorage, setTimeout, console, location zB. window.innerWidth. window ist dabei Standard und muss nicht geschrieben werden.
  • screen: Bildschirminfos wie screen.width (fast nie gebraucht)
  • navigator: Browserinfos / Geräteinfos zB navigator.language

Event Listener

Ein Event Listener ist eine Funktion, die auftritt, wenn ein bestimmtes Event (z.B. Klick, Hover) auf einem Element passiert. Sie ermöglicht es, auf Benutzerinteraktionen zu reagieren und dynamische Aktionen auszuführen. 

element.addEventListener('click', function() {
  // Aktion bei Klick
});

Der erste Parameter ist der Event-Type, der zweite die Funtion, die ausgeführt wird, wenn das Event eintritt.

Man unterscheidet grob verschiedene Kategorien von Events:

Beispiel: Button Klick Event Listener

document.addEventListener('DOMContentLoaded', () => {
  const button = document.getElementById('myButton');
  button.addEventListener('click', () => {
    alert('Button wurde geklickt!');
  });
});

getElementById() ist eine Methode des DOM, um ein Element anhand seiner ID zu finden.

getElementByClassName() ist eine Methode des DOM, um Elemente anhand ihres Klassennamens zu finden.

querySelector() ist eine Methode des DOM, um das erste Element zu finden, das einem CSS-Selektor entspricht.

querySelectorAll() ist eine Methode des DOM, um alle Elemente zu finden, die einem CSS-Selektor entsprechen.

getElementByTagName() ist eine Methode des DOM, um alle Elemente zu finden, die einem HTML-Tagnamen entsprechen.

Schlüsselwort return

return verlässt die Funktion sofort.

zB if (!button) return; // Funktion verlassen, wenn Button nicht gefunden wurde (Guard Clause). Dann wird restlicher Code garnicht erst ausgeführt. Dadurch werden Fehler vermieden, wenn das Element nicht da ist.

const rect = section.getBoundingClientRect();

Gibt ein Objekt mit der Größe und Position eines Elements in Bezug zum Viewport zurück (in dem Fall section). 

{ top: 120,
          bottom: 820,
          left: 0,
          right: 0,
          width: 1440,
          height: 700
    }

rect.top = 0 bedeutet also, dass das Element genau oben im Viewport beginnt.

rect.top = -300 wäre der gescrollte Zustand, also 300px oben raus

const styles = window.getComputedStyle(section);

Damit holt man sich alle berechneten CSS Werte eines Elements. Also zB margin-top

const marginTop = parseFloat(styles.marginTop) || 0;

wandelt einen String in eine Fließkommazahl (Number) um. Also 20px in 20 und 1.5em in 1.5, auto wird zu NaN, daher || 0
