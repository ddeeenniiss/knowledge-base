Event Bubbling

Eine gute Doku für Event Bubbling gibt es HIER

Wenn ein Ereignis (zB Klick) auf einem Element ausgelöst wird, wird es zunächst auf diesem Element behandelt und dann an das übergeordnete Element weitergeleitet.

closest()

Die closest() Methode sucht das nächste Eltern- oder Geschwisterelement. Bei Klick Events läuft durch Event Bubbling der Klick auf allen Eltern-Elementen durch. Somit reagiert das nächste Element, welches die closest Klasse hat.

stopPropagation() => Vermehrung stoppen

Manchmal kann Event Bubbling auch zu unerwünschten Effekten führen. Mit stopPropagation() verhindert man das hoch bubblen eines Events zu Parent Elementen. 

      video.addEventListener("click", (event) => {
        event.stopPropagation();
      });

Event Capture

Event Capture ist wie Event Bubbling, aber in umgekehrter Richtung. In den meisten Fällen kann Event Bubbling verwendet werden. Das Event feuert hier zuerst auf dem übergeordneten Element geht dann immer tiefer in das DOM. Um Event Capture zu aktivieren muss die capture Option auf addEventListener gesetzt werden 

      container.addEventListener("click", handleClick, { capture: true });

Event Delegation => Event Weiterleitung

Wenn wir viele Kinds-Elemente in einem Parent Element haben, dann könnte man auf jedes einzelne Kind-Element einen Event Listener setzen. Man könnte aber auch nur einen Event Listener auf das Parent Element setzen und dann mit Event Bubbling hochbubblen. Das richtige Element wird durch event.target erkannt.

event Objekt

event ansich ist einfach ein Objekt mit Informationen über das Ereignis. Hier eine Übersicht:

event.target

event.target gibt das Element zurück, wo das Event gestartet wurde. Der Browser erkennt das Element anhand der Position auf dem Bildschirm.

event.currentTarget

event.currentTarget gibt das Element zurück, auf dem der Listener sitzt. Meist ein Parent Element.

JavaScript ist aktiver Code, der im Browser ausgeführt wird. Das ist potentielles Sicherheitsrisiko. Das Grundprinzip der Sicherheit ist Sandbox (eingesperrt ohne Zugriff auf Dateisystem). XSS - Cross Site Scripting

Einbinden von schädlichem JavaScript in eine andere, vertrauenswürdige Seite. zB über Formulareingaben oder HTTP Parameter.

Um das vorzubeugen muss verhindert werden, dass eingegebene Daten Skripte enthalten können.

IntersectionObserver

Der IntersectionObserver ermöglicht es, das Sichtbarkeitsverhalten von Elementen im Viewport zu überwachen. Dies ist besonders nützlich für Lazy Loading von Bildern, Infinite Scrolling oder das Auslösen von Animationen, wenn ein Element in den sichtbaren Bereich des Bildschirms gelangt.

Beispiel: Module bei straehle, die in den Bildschirm einfaden

  
    document.addEventListener('DOMContentLoaded', () => {
  const elements = document.querySelectorAll<HTMLElement>('.animate-on-scroll');

  const observer = new IntersectionObserver(
    (entries, obs) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-visible');
          obs.unobserve(entry.target); // nur einmal animieren
        }
      });
    },
    {
      threshold: 0.1 // 10% sichtbar = Animation starten
    }
  );

  elements.forEach(el => observer.observe(el));
});

DOMContentLoaded

Das DOMContentLoaded-Ereignis tritt auf, sobald der HTML-Dokument-Inhalt vollständig geladen und geparst wurde, ohne auf externe Ressourcen wie Bilder oder Skripte zu warten. Es ist nützlich, um sicherzustellen, dass das DOM (zB. Buttons, Listen, Nav Elemente) bereit ist, bevor JavaScript-Operationen ausgeführt werden.

Ist dann nötig, wenn JS direkt im Head steht, da dann das JS durchläuft ohne dass die HTML Elemente schon da sind. Unnötig, wenn Skript am Ende nach HTML steht. 

document.addEventListener('DOMContentLoaded', () => {});

defer

Eine Alternative zu DOMContentLoaded ist defer. Während DOMContentLoaded das Skript blockiert, bis das DOM geladen ist, ermöglicht defer das Laden des Skripts im Hintergrund, während das HTML geparst wird. Das Skript wird erst ausgeführt, wenn das DOM vollständig geladen ist, aber es blockiert nicht den Parsing-Prozess.

DOM (Document Object Model)

ist eine Schnittstelle, um den Inhalt, die Struktur und das Styling eines HTML-Dokuments dynamisch zu verändern. Es repräsentiert das Dokument als Baumstruktur, wobei jedes Element im Baum ein Objekt ist, das über JavaScript manipuliert werden kann. Der Einstiegspunkt dafür ist .document

Es gibt dabei drei wirkliche Wurzeln:

  • window: aktuelles Browserfenster, globales Objekt im Browser. Darauf liegen zB document, localStorage, setTimeout, console, location zB. window.innerWidth. window ist dabei Standard und muss nicht geschrieben werden.
  • screen: Bildschirminfos wie screen.width (fast nie gebraucht)
  • navigator: Browserinfos / Geräteinfos zB navigator.language

Event Listener

Ein Event Listener ist eine Funktion, die auftritt, wenn ein bestimmtes Event (z.B. Klick, Hover) auf einem Element passiert. Sie ermöglicht es, auf Benutzerinteraktionen zu reagieren und dynamische Aktionen auszuführen. 

element.addEventListener('click', function() {
  // Aktion bei Klick
});

Der erste Parameter ist der Event-Type, der zweite die Funtion, die ausgeführt wird, wenn das Event eintritt.

Man unterscheidet grob verschiedene Kategorien von Events:

Kategorie Event-Type Beschreibung Beispiele
Maus-Events click Wird ausgelöst, wenn der Nutzer auf ein Element klickt dblclick Wird ausgelöst, wenn der Nutzer auf ein Element doppelt klickt mousemove Wird ausgelöst, wenn der Nutzer über ein Element bewegt. mousedown Wird ausgelöst, sobald eine Maustaste gedrückt wird (ohne loslassen) mouseup Wird ausgelöst, sobald eine Maustaste losgelassen wird.
Keyboard-Events keydown Wird ausgelöst, sobald eine Taste gedrückt wird. keyup Wird ausgelöst, sobald eine Taste losgelassen wird.
Window-Events resize Wird ausgelöst, sobald die Browser-Fenstergröße geändert wird. scroll Wird ausgeführt, sobald der Benutzer den Inhalt eines Elements scrollt. load Wird ausgeführt, sobald die Seite geladen ist (Heute durch DOMContentLoaded ersetzt)
Form-/Input-Events input Wird ausgelöst bei jeder Änderung eines Input Elements change Wird ausgelöst, sobald ein Input Eingabe abgeschlossen wurde. submit Wird ausgelöst, sobald ein Formular abgesendet wird. focus Wird ausgelöst, sobald ein Element Fokus erhält. (Bei Input Klick oder Tab gedrückt) blur Wird ausgelöst, sobald ein Element den Fokus verliert.
Touch-/Pointer-Events touchstart Wird ausgelöst, sobald der Finger den Bildschirm berührt. touchmove Wird ausgelöst, sobald der Finger sich auf dem Bildschirm bewegt. pointerdown Wird ausgeführt, sobald ein Zeiger (z.B. Maus, Finger) auf ein Element geklickt wird. pointermove Wird ausgeführt, sobald ein Zeiger (z.B. Maus, Finger) über ein Element bewegt wird. pointerup Wird ausgeführt, sobald ein Zeiger (z.B. Maus, Finger) von einem Element losgelassen wird.
Drag&Drop-Events dragstart Wird ausgeführt, sobald das Ziehen eines Elements begonnen wird. dragover Wird ausgelöst, sobald das Ziehen eines Elements über ein anderes Element gezogen wird. drop Wird ausgelöst, sobald ein gezogenes Element abgelegt wird.
Clipboard-Events copy Wird ausgelöst, sobald ein Nutzer etwas kopiert. paste Wird ausgelöst, sobald ein Nutzer etwas einfügt.
Animations-/Transition-Events animationend Wird ausgelöst, sobald eine CSS Animation beendet ist. transitionend Wird ausgelöst, sobald eine CSS Transition beendet ist.

Beispiel: Button Klick Event Listener

document.addEventListener('DOMContentLoaded', () => {
  const button = document.getElementById('myButton');
  button.addEventListener('click', () => {
    alert('Button wurde geklickt!');
  });
});

getElementById() ist eine Methode des DOM, um ein Element anhand seiner ID zu finden.

getElementByClassName() ist eine Methode des DOM, um Elemente anhand ihres Klassennamens zu finden.

querySelector() ist eine Methode des DOM, um das erste Element zu finden, das einem CSS-Selektor entspricht.

querySelectorAll() ist eine Methode des DOM, um alle Elemente zu finden, die einem CSS-Selektor entsprechen.

getElementByTagName() ist eine Methode des DOM, um alle Elemente zu finden, die einem HTML-Tagnamen entsprechen.

Schlüsselwort return

return verlässt die Funktion sofort.

zB if (!button) return; // Funktion verlassen, wenn Button nicht gefunden wurde (Guard Clause). Dann wird restlicher Code garnicht erst ausgeführt. Dadurch werden Fehler vermieden, wenn das Element nicht da ist.

const rect = section.getBoundingClientRect();

Gibt ein Objekt mit der Größe und Position eines Elements in Bezug zum Viewport zurück (in dem Fall section). 

{ top: 120,
          bottom: 820,
          left: 0,
          right: 0,
          width: 1440,
          height: 700
    }

rect.top = 0 bedeutet also, dass das Element genau oben im Viewport beginnt.

rect.top = -300 wäre der gescrollte Zustand, also 300px oben raus

const styles = window.getComputedStyle(section);

Damit holt man sich alle berechneten CSS Werte eines Elements. Also zB margin-top

const marginTop = parseFloat(styles.marginTop) || 0;

wandelt einen String in eine Fließkommazahl (Number) um. Also 20px in 20 und 1.5em in 1.5, auto wird zu NaN, daher || 0
