mform

mform ist ein AddOn, dass dir beim Erstellen von Eingabeformularen für Module hilft. Du musst also nicht alles selbst in HTML bauen, sondern kannst über eine PHP-API Felder generieren. Einbindung: use FriendsOfRedaxo\MForm; $mform = new MForm();

$mform->addFieldsetArea('Inhalt'); $mform->addTextField(1, ['label' => 'Überschrift', 'full' => true]); $mform->addTextAreaField(2, ['label' => 'Text', 'rows' => 6]);

Bilder

Für Bilder gibt es das MediaField, das die Auswahl von Bildern aus der Mediathek ermöglicht.
$mform->addMediaField(3, ['label' => 'Bild', 'full' => true]);

Links

$mform->addLinkField(6, ['label' => 'Seitenlink']);

Checkbox

$mform->addCheckboxField(7, ['label' => 'Aktivieren?']);

Dropdown:

$mform->addSelectField(8, ['label' => 'Auswahl']); ->setOptions(['opt1' => 'Option 1', 'opt2' => 'Option 2']);

Methoden

rex_escape() schützt vor XSS, indem Sonderzeichen umgewandelt werden.

nl2br() wandelt Zeilenumbrüche in br Tags um.

rex_getUrl() erzeugt eine URL aus einer Artikel-ID. Mit rex_getUrl(5) wird daraus die richtige URL für den Artikel mit der ID 5. Falls man zu einem Bereich im selben Artikel springen möchte, geht das so: $btnLink = rex_getUrl(5), '#kontakt';
