Die Skriptsprache Python

Python ist eine moderne Skriptsprache, die plattformunabhängig ist. Sie kann also auf sämtlichen Betriebssystemen laufen, da jedes Betriebssystem einen eigenen Interpreter hat. Sie ist objektorientiert.

Hier die Python Dokumentation: CLICK ME

Python Dateien haben die Endung .py. Python speichert zudem immer den Bytecode in einer Datei mit Endung .pyc

Semikolon

Das Semikolon ist in Python nicht zum Abschluss einer Anweisung notwendig, es genügt schon das normale Zeilenende. Anweisungen die über mehrere Zeilen laufen müssen am Ende allerdings durch ein \ zusammengefügt werden.

Kommentare

Kommentare werden in Python durch ein # angegeben.

Datentypen

Python unterscheidet ganze Zahlen (beliebig groß), Gleitkommazahlen, imaginäre/komplexe Zahlen und boolean

Division

Ein / bedeutet div in Python. // bedeutet Gleitkommadivision.

Zeichenketten

kurze Zeichenkettenliterale werden in Python durch ' oder " begrenzt. Lange Zeichenkettenliterale können über mehrere Zeilen reichen

Zeichenketten können mit einem + miteinander verbunden werden.
