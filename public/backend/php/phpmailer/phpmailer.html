Konfiguration

Hier werden generelle Einstellungen getätigt. Ansich trivial. Mailertyp wird dann unterschieden in mail, smtp, sendmail.

mail (PHP mail()) – rex_mailer() nutzt standardmäßig die PHP-eigene mail()-Funktion. Die Mail wird dabei nicht direkt ins Internet verschickt, sondern über den in php.ini hinterlegten sendmail_path an den lokal auf dem Server laufenden Mailserver bzw. MTA übergeben (z. B. Sendmail, Postfix, Exim). Von dort wird sie in eine lokale Warteschlange gestellt und je nach Serverauslastung und Konfiguration mit Verzögerung – von wenigen Sekunden bis hin zu mehreren Minuten – an den eigentlichen Empfänger-Mailserver weitergeleitet. Die Zustellzeit ist dadurch tendenziell langsamer und weniger vorhersehbar. Da hierbei keine Authentifizierung stattfindet und die Mail direkt von der Server-IP verschickt wird, stufen viele Empfänger-Mailserver diese Zustellung als potenzielles Spam-Risiko ein, insbesondere wenn SPF, DKIM oder der Reverse-DNS-Eintrag der Server-IP nicht zur Absenderdomain passen.

sendmail – Hierbei umgeht PHPMailer die PHP mail()-Funktion und übergibt die Mail stattdessen direkt per Pipe an das lokale Sendmail-Programm (bzw. dessen Postfix- oder Exim-kompatiblen Wrapper) auf dem Server. Ein Login ist nicht nötig, da die Übergabe rein intern erfolgt. Technisch landet die Mail dabei im selben lokalen Warteschlangen-Mechanismus wie bei "mail" – Zustellzeit und Spam-Risiko verhalten sich daher nahezu identisch: eher langsame Zustellung, da die Mail zunächst lokal verarbeitet wird, und ein erhöhtes Spam-Risiko mangels Authentifizierung.

SMTP – Hierfür werden Host, Port, Verschlüsselung, Verschlüsselungstyp, Authentifizierung sowie Benutzername und Passwort benötigt. PHP verbindet sich direkt und verschlüsselt mit dem angegebenen SMTP-Server und liefert die Mail ohne Umweg über eine lokale Warteschlange aus. In der Praxis kommt dabei meist Port 587 (STARTTLS) oder Port 465 (SSL/TLS) zum Einsatz; Port 25 ist zwar der historische SMTP-Standardport, wird für authentifizierten Versand aus Anwendungen heraus aber kaum noch genutzt und ist bei vielen Hostern für ausgehende Verbindungen gesperrt. Da SMTP eine Authentifizierung per Benutzername und Passwort erfordert und die Mail direkt beim autorisierten Mailserver-Provider eingeliefert wird, ist die Zustellung in der Regel schnell und das Spam-Risiko deutlich geringer.

php.ini

Die php.ini dient dem PHP Server als Konfigurationsdatei. Sie können die PHP Einstellungen ändern, indem Sie die entsprechenden Anweisungen, sogenannte php.ini Direktiven in die php.ini eintragen.

Email-Versand

$mail->setFrom()

Die Methode setFrom() legt den Absender der E-Mail fest. Ist diese nicht gesetzt, dann wird PHPMailer automatisch eine Absenderadresse verwenden, die auf dem Server konfiguriert ist oder lässt sie leer. Viele Mailserver lehnen solche Mails ab oder droppen diese, obwohl PHPMailer die Mail als erfolgreich versendet zurückgibt.

$mail->addAddress()

Die Methode addAddress() fügt eine Empfängeradresse hinzu.

$mail->addReplyTo()

Die Methode addReplyTo() fügt eine Reply-To-Adresse hinzu. Also wenn auf eine E-Mail geantwortet wird, dann geht sie an diese Email-Adresse. Erster Parameter ist die Email-Adresse, zweiter Parameter ist der Name. $mail->addReplyTo($formData['email'], $formData['name']);

Was wird benötigt um eine Mail zu senden? (sendmail)

1. Eine funktionierende PHP Installation (Sendmail oder SMTP) mit korrekter Konfiguration (ist bei PHP schon konfiguriert)

2. Absenderadresse (bei sendmail kein Passwort notwendig, bei SMTP schon)

3. Empfängeradresse

4. HTML Formular (name ist der Name im $POST['name'] Array)

      

        Name: 

        Email: 

        Nachricht:

5. PHP Verarbeitung

      < ?php
      if($_SERVER["REQUEST_METHOD"] === "POST"){

        // Daten aus dem Formular
        $name = trim($_POST['name'] ?? '');
        $email = trim($_POST['email'] ?? '');
        $message = trim($_POST['message'] ?? '');

        // Empfängeradresse
        $recipient = 'empfaenger@example.com';

        // Betreff und Body der E-Mail
        $subject = "Neue Nachricht von $name";
        $body = "Name: $name\n";
        $body .= "Email: $email\n";
        $body .= "Nachricht: $message\n";

        // PHP Mailer vorbereiten
        $mail = new PHPMailer();

        // Sendmail aktivieren
        $mail->isSendmail();

        // Absenderadresse
        $mail->setFrom('info@example.de', 'Meine Webseite');
        $mail->addReplyTo($email, $name);

        // Empfänger
        $mail->addAddress($recipient);

        //Betreff und Body
        $mail->Subject = $subject;
        $mail->Body = $body;

        // E-Mail senden
        if($mail->send()){
          echo "Email erfolgreich gesendet!";
        } else {
          echo "Fehler beim Senden:" . $mail->ErrorInfo;
        }
      }
