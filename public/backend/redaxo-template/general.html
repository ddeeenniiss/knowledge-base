Redaxo Template Allgemein

Struktur Erklärung

In Redaxo selbst gibt es einen core unter public/redaxo/src/core. Dieser sollte nicht bearbeitet werden, da bei Updates alles überschrieben werden würde.

Unter public/redaxo/src/addons werden Inhalte eigentlich bearbeitet. Hier liegt in diesem Fall das Addon project, welches die Inhalte wie zB footer überschreibt.

Backend Module

Unter public/redaxo/src/core/fragments/core/footer.php liegen die Backend Module. zB die footer.php wird nur im Redaxo Backend verwendet. Das sind core Module, die die Redaxo Seite per se strukturieren. Die gehören also allgemein zu Redaxo und nicht zu einem spezifischen Projekt wie zB Menges & Partner. Wird erkannt an der Klasse rex-global-footer.

Frontend Module

Generell im Addon project liegen module und templates. Unter public/redaxo/src/addons/project/templates/inc_footer.php zB liegen die Module, die letzlich im Frontend für den Kunden sichtbar sind.

Farbklassen Definitionen

Bei Tailwind gibt es eine feste Konvention:

text-{color} erzeugt immer color: var(--color-{color}).

Für text-white gilt dann also:

.text-white { 
			color: var(--color-white); 
		 }
