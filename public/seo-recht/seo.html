Kurz: Es zeigt dir, ob deine Website funktioniert und wie sie sich entwickelt.

Wichtig hierbei ist die Performance der Landing Pages. Kommen genug Leute darauf und wird das Kontaktformular genutzt? Kommen genug Besucher über die SEO?

Consent Management (Cookies)

Wie Cookies funktionieren

Ein Cookie ist ein kleiner Textwert, den eine Website im Browser speichern lassen kann. Der Server sendet ihn meist im HTTP-Header Set-Cookie an den Browser. Dieser speichert ihn entsprechend seiner Eigenschaften, zum Beispiel für welche Domain und welchen Pfad er gilt und wie lange er gültig ist.

Bei einer späteren Anfrage an eine passende Adresse sendet der Browser den Cookie-Wert automatisch im Cookie-Header zurück. Der Server kann den Wert dann einer Sitzung zuordnen, etwa um einen Login oder Warenkorb wiederzuerkennen. Häufig enthält das Cookie dafür nur eine zufällige Sitzungs-ID; die eigentlichen Sitzungsdaten liegen auf dem Server. Ein Ablaufdatum oder eine Löschung beendet die Speicherung.

Vereinfacht läuft das so ab:

  1. Der Browser sendet eine Anfrage an die Website.
  2. Der Server antwortet und kann mit Set-Cookie einen Cookie setzen.
  3. Der Browser speichert den Cookie gemäß Gültigkeit und weiteren Attributen.
  4. Bei passenden Folgeanfragen sendet der Browser ihn im Cookie-Header zurück.
  5. Der Server verwendet den Wert, zum Beispiel zum Wiedererkennen einer Sitzung.

Vorteile von Cookies

  • Sie ermöglichen Sitzungen über mehrere HTTP-Anfragen hinweg, obwohl HTTP selbst zustandslos ist.
  • Login-Status, Warenkörbe und persönliche Einstellungen können wiedererkannt werden.
  • Sie funktionieren ohne zusätzliche Abfrage, weil der Browser passende Cookies automatisch mitsendet.

Nachteile und Risiken

  • Cookies können zur Wiedererkennung und zum Tracking verwendet werden; das kann die Privatsphäre beeinträchtigen.
  • Werden Sitzungs-Cookies gestohlen, kann ein Angreifer unter Umständen eine Sitzung übernehmen. HTTPS sowie passende Attribute wie Secure, HttpOnly und SameSite senken Risiken.
  • Cookies werden bei passenden Anfragen mitgesendet und vergrößern dadurch die übertragenen Header.
  • Abgelaufene oder gelöschte Cookies können Sitzungen und gespeicherte Einstellungen beenden; Browser schränken außerdem bestimmte Drittanbieter-Cookies ein.

Einwilligung und Consent Management

Technisch notwendige Cookies können ohne Einwilligung zulässig sein, wenn sie für einen ausdrücklich gewünschten Dienst erforderlich sind. Für nicht notwendige Cookies, etwa für Analyse oder Marketing, ist in der Regel eine vorherige Einwilligung erforderlich. Die konkreten Anforderungen hängen vom Einsatz ab; ein Consent-Banner sollte eine echte Auswahl ermöglichen, zum Beispiel „Alle akzeptieren“, „Nur notwendige“ und „Individuelle Auswahl“.

Ein Consent-Management-Tool speichert die gewählten Kategorien und kann den Zeitpunkt der Auswahl dokumentieren. Es muss außerdem ermöglichen, eine Einwilligung später zu ändern oder zu widerrufen. Beispiele für Consent-Management-Plattformen (CMPs) sind Usercentrics, Borlabs Cookie, Cookiebot und Complianz.

Consent Tools arbeiten mit data-attributes (data-cookiecategory="statistics")

SEO

Die SEO (Search Engine Optimization /Suchmaschinenoptimierung) umfasst alle Maßnahmen, die dazu dienen, eine Website in Browsern besser sichtbar zu machen und mehr organischen Traffic zu erhalten. Dabei geht es nicht nur um Keywords, sondern um eine Kombination aus Technik, Inhalt, Struktur und Autorität.

Technisches Design

Browser müssen die Website einfach crawlen, verstehen und indexieren können.

  • Ladegeschwindigkeit
  • Mobile Optimierung (Responsive Design)
  • Saubere URL-Struktur
  • SSL / HTTPS
  • XML Sitemap
  • robots.txt: Ist im Root einer Website und teilt Browsern mit welche Bereiche sie crawlen dürfen oder nicht. 
        User-agent: * // Für welchen Bot gelten die Regeln
    Disallow: /admin/ //Admin Bereich wird ignoriert
    Allow: / //Alles andere ist erlaubt
  • Core Web Vitals
  • Strukturiertes Markup
  • CDN: Content Delivery Network: Ist ein Netzwerk aus Servern weltweit, das Website Inhalte näher zum Nutzer bringt. CDN speichert Kopien der Website auf den Servern weltweit, dadurch lädt die Seite schneller. CDN liefert Bilder, CSS, JavaSkript, Videos, statische Dateien. Anbieter sind zB Cloudflare, AWS, Fastly, Akamai und BunnyCDN.
  • Lazy Loading: Inhalte werden erst dann geladen, wenn sie gebraucht werden. Wenn sie also im sichtbaren Bereich des Nutzers erscheinen. Also erst wenn der Nutzer dahin scrollt wo die Inhalte sind. Eingefügt wird das einfach per Attribut loading="lazy". Angewendet wird das bei Bildern, Videos, Iframes

Verbesserungen hier sind unter anderen komprimierte Bilder, Lazy Loading, Code minimieren (CSS/JS), CDN verwenden und Server Performance verbessern.

Je Nach Kategorie gibt es auch bei Werten von 100 folgende Risiken:

  • Performance 100 bedeutet sehr gute Messwerte im Lighthouse Test, aber es bedeutet nicht, dass jeder Besucher dieselbe Ladezeit erlebt.
  • Accessibility 100 bedeutet, dass alle bewerteten automatischen Prüfungen bestanden sind, aber es bedeutet nicht automatisch vollständige Barrierefreiheit oder WCAG-Konformität.
  • Best Practices 100 bedeutet, dass alle bewerteten Prüfungen bestanden sind, aber es bedeutet nicht, dass die Website fehlerfrei oder vollständig sicher ist.
  • SEO 100 bedeutet, dass alle bewerteten SEO-Prüfungen bestanden sind, aber es bedeutet nicht, dass das Ranking automatisch auf Platz 1 bzw gut ist.

Wo finde ich LCP, INP und CLS?

In Chrome findest du diese Werte über Google PageSpeed Insights unter https://pagespeed.web.dev/. Gib dort deine Website-URL ein. Unter „Core Web Vitals“ werden die realen Nutzungsdaten angezeigt, sofern genügend Felddaten vorhanden sind. Weiter unten findest du zusätzliche Lighthouse-Labormessungen. Alternativ kannst du in Chrome DevTools unter „Lighthouse“ und „Performance“ weitere Analysen durchführen. Beachte, dass INP nicht direkt im normalen Lighthouse-Labortest gemessen wird, da dafür reale Nutzerinteraktionen erforderlich sind.

LCP (Largest Contentful Paint) – Ladegeschwindigkeit

LCP misst, wie lange es dauert, bis das größte sichtbare Inhaltselement im sichtbaren Seitenbereich dargestellt wird. Das kann beispielsweise ein großes Bild, ein Titel oder ein Textblock sein. Ein niedriger Wert bedeutet, dass Nutzer den Hauptinhalt schnell sehen. Zielwert: maximal 2,5 Sekunden. Zwischen 2,5 und 4 Sekunden besteht Verbesserungsbedarf. Über 4 Sekunden gilt der Wert als schlecht.

INP (Interaction to Next Paint) – Reaktionsfähigkeit

INP misst, wie schnell eine Website auf Nutzerinteraktionen reagiert, beispielsweise auf einen Klick auf das Menü, einen Button oder eine Formularfunktion. Ein niedriger Wert sorgt dafür, dass sich die Website flüssig und unmittelbar bedienbar anfühlt. Zielwert: maximal 200 Millisekunden. Zwischen 200 und 500 Millisekunden besteht Verbesserungsbedarf. Über 500 Millisekunden gilt der Wert als schlecht.

CLS (Cumulative Layout Shift) – visuelle Stabilität

CLS misst, wie stark sich sichtbare Seitenelemente unerwartet verschieben. Das passiert beispielsweise, wenn Bilder ohne reservierten Platz nachgeladen werden oder Schriftarten das Layout verändern. Ein niedriger Wert bedeutet, dass die Seite beim Laden stabil bleibt und Nutzer nicht versehentlich auf das falsche Element klicken. Zielwert: maximal 0,1. Zwischen 0,1 und 0,25 besteht Verbesserungsbedarf. Über 0,25 gilt der Wert als schlecht.

Welche Werte sollte ich insgesamt anstreben?

Für eine gute Nutzererfahrung sollten alle drei Core Web Vitals folgende Grenzwerte erreichen: LCP ≤ 2,5 Sekunden, INP ≤ 200 Millisekunden und CLS ≤ 0,1. Entscheidend sind die realen Nutzerdaten am 75. Perzentil. Das bedeutet, dass mindestens 75 Prozent der Seitenbesuche innerhalb dieser Grenzwerte liegen. Wenn noch keine ausreichenden Felddaten vorhanden sind, kannst du zunächst die Lighthouse-Labormessungen zur Optimierung verwenden. Diese ersetzen jedoch nicht die Messungen unter realen Nutzungsbedingungen.

On-Page SEO

Hier geht es um Inhalte und Struktur auf der Website

  • Keyword Recherche
  • Titel (title Tag)
  • Meta Description
  • Überschriftenstruktur
  • Textqualität
  • interne Verlinkung
  • Bild-SEO (Alt Tags)

Verbesserungen hier sind die Optimierung auf Suchintentionen, eine klare Struktur, bessere interne Verlinkung, längere und wertvolle Inhalte und Duplicate Content vermeiden

Content SEO

Content ist einer der wichtigsten Ranking Faktoren. Ziel ist es Content zu erstellen, der Fragen beantwortet, Mehrwert liefert, Keywords natürlich integriert und regelmäßig aktualisiert wird.

Verbesserungen hier sind ein Keyword Cluster, Content regelmäßig aktualisieren, Topic Authority aufbauen, Long Tail Keyword nutzen

Off-Page SEO

Das sind Signale von anderen Websites, die Vertrauen erzeugen. zB Backlinks, Domain Authority, Marken Erwähnungen und Social Signals

UX & Engagement Signale

Google bewertet auch, wie Nutzer mit der Seite interagieren.

  • Click Through Rate (CTR)
  • Absprungrate
  • Verweildauer
  • Pages per Session

Wo kann die SEO eingesehen werden?

In der Google Search Console (Ranking und Keywords), Google Analytics (Traffic und Verhalten), Ahrefs/SEMrush (Konkurrenz & Backlinks), PageSpeed Insights (technische Performance). Diese zeigt, wie deine Website direkt in der Google Suche performt.
