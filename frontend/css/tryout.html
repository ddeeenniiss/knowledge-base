Wie am besten Bilder stylen?

img { max-width: 100%; height: auto; display: block; min-width: 0; //wichtig bei Flex Containern}

Flexbox img hat standardmäßig min-width: auto;

wenn Bild variabel sein soll, dann flex: 1; min-width: 0; max-width: 100%; height: auto;

Wenn min-width und max-width gesetzt sind, dann gewinnt min-width

aspect-ratio

benötigt nur eine dimension, die andere wird automatisch berechnet. zB so: height: 200px; aspect-ratio: 16 / 9;

oder responsive an container: width: 100%; aspect-ratio: 16 / 9;

Mit parent dann: .container { max-width: 800px; } .box { width: 100%; aspect-ratio: 16 / 9; }

oder pro breakpoint: .box { width: 100%; aspect-ratio: 1 / 1; } @media (min-width: 768px) { .box { aspect-ratio: 16 / 9; } } @media (min-width: 1200px) { .box { aspect-ratio: 21 / 9; } }

Responsive mit grid

.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); } .box { width: 100%; aspect-ratio: 16 / 9; }

Wann Flexbox und wann Grid?

Flexbox = 1 Dimension (Reihe ODER Spalte) und wenn Content ausgerichtet werden soll

Grid bei Spalten und Zeilen oder komplexen Layouts.

Niemals vw und vh auf html oder body setzen

100vw bedeutet die komplette Bildschirmbreite. Dazu kommt aber noch die Scrollbar on top. Somit entsteht overflow-x.

dvh für mobile headerbars nutzen

dynamic viewport height ersetzt den Platz für viewport Elemente von Browsern wie zB Suchleiste, sobald diese durch scrollen verschwinden.

min Funktion für section wrapper

Anstatt width: 100% und max-width: 1920px zu nutzen, kann man auch width: min(100%, 1920px) nutzen

lieber margin: 0 auto; anstatt margin-inline: auto; setzen

Setzt direkt alles.

Standard margin oder padding

Margin-top und Margin-bottom: Standardmäßig haben h1-h6, p, ul, ol,

margin hat body, figure

padding-left: standardmäßig haben das ul, ol

padding hat button

padding und border hat input

Chrome Responsive Modus

Preset Modus: device-simulated viewport area inkl Scrollbar Reservierung (1920px werden zu 1905px). Dieser Modus simuliert die tatsächliche Viewportgröße inkl der Scrollbar, was zu einer reduzierten Breite führt.

Resize Modus: Layout Viewport per größer ziehen mit Maus: kein device-simulated layer (1920px bleiben 1920px).
