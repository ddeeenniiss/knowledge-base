Formular ohne AJAX per PHP

Formular

Form Tag

Das form Tag ist ein Container für Eingabefelder, Kontrollkästchen, Optionsfelder, Absendeschaltflächen

Input Element

Das input Element ist ein Eingabefeld mit verschiedenen type Attributen:

  • type="text": zeigt ein einzeiliges Texteingabefeld an
  • type="radio": zeigt ein Optionsfeld an
  • type="checkbox": zeigt ein Kontrollkästchen an
  • type="email": zeigt ein E-Mail Eingabefeld an
  • type="tel": zeigt eine anklickbare Fläche an

Action Attribut

Das action Attribut definiert die Aktion, die beim Absenden des Formulars ausgeführt wird.

Label Tag

Das label Tag definiert eine Bezeichnung für viele Formularelemente. Es wird von Screenreadern erkannt und vorgelesen wenn der Nutzer es fokussiert. Wenn innerhalb des Label Elements geklickt wird, dann wird das Kontrollkästchen umgeschaltet.

method Attribut

Das method Attribut definiert die Methode, mit der die Formulardaten an den Server gesendet werden. Als URL Variablen mit get oder als HTTP Post Transaktion mit post.

submit Attribut

type="submit" definiert eine Schaltfläche, die das Formular absendet an einen Formular-Handler. Dieser ist eine Datei auf dem Server, die die Daten verarbeitet.

name Attribut

Das name Attribut ist ein einzigartiger Name für jedes Formularelement. Es wird vom Server verwendet, um die Daten zu identifizieren. Ist kein name Attribut vorhanden, wird das Element nicht an den Server gesendet.

autocomplete Attribut

steuert, ob der Browser automatisch Daten vervollständigen soll oder nicht.

novalidate Attribut

Formulardaten (Eingabe) werden nicht vom Browservalidiert. Sinnvoll dann, wenn man eigene Validierungen durchführen möchte.

output Element

Das output Element zeigt Ergebnisse von Berechnungen an.

HTML input Typen

type="text"

definiert einzeiliges Texteingabefeld

type="password"

definiert ein Passwortfeld, das die Eingabe maskiert

type="submit"

definiert eine Schaltfläche zum Absenden von Formulardaten an einen Formular-Handler. Dieser wird im action Attribut definiert.

type="reset"

definiert eine Schaltfläche zum Zurücksetzen aller Formulardaten auf ihre Standardwerte

type="radio"

definiert ein Radio Button Optionsfeld

type="checkbox"

definiert ein Kontrollkästchen

type="button"

definiert eine Schaltfläche ohne automatisches Absenden

type="color"

definiert ein Farbfeld

type="date"

definiert ein Datumsfeld. mit den Attributen min und max kann hierbei ein minimales und maximales Datum definiert werden.

type="datetime-local

definiert ein Datums- und Zeitfeld

type="email"

definiert ein E-Mail Eingabefeld

type="image"

definiert ein Bild als Absende-Schaltfläche

type="file"

definiert ein Dateiupload-Feld

type="hidden"

definiert ein verstecktes Feld, das in den Browsertools sichtbar ist. Es wird verwendet, um Daten zu speichern, die nicht vom Benutzer eingegeben werden sollen, aber dennoch an den Server gesendet werden müssen.

type="month"

definiert ein Monats/ Jahrfeld

type="number"

definiert ein Zahlenfeld. Attribute min und max können eingegeben werden, um die Werte zu begrenzen. Mit step kann die Schrittweite definiert werden.

type="range"

definiert ein Zahlenfeld mit einem Schieberegler. Attribute min, max und step ebenfalls anwendbar.

type="search"

definiert ein Suchfeld

type="search"

definiert ein Suchfeld mit Suchvorschlägen. Verhält sich wie ein normales Textfeld. Ist nur semantisch gedacht für Suchfelder. Hilft Suchmaschinen und Screenreadern, die Funktion des Feldes zu verstehen.

type="tel"

definiert ein Telefonnummer-Feld. Über das pattern Attribut lassen sich Validierungen definieren.

type="time"

definiert ein Zeitfeld

type="url"

definiert ein URL-Feld. Kann beim Absenden automatisch validiert werden.

Eingabeattribute

value

definiert einen Standardwert für das Eingabefeld.

readonly

definiert ein Eingabefeld, das nicht editierbar ist. Es ist allerdings fokussierbar und kopierbar.

disabled

definiert ein Eingabefeld, das nicht editierbar und nicht fokussierbar, klickbar ist.

maxlength

definiert die maximale Länge des Textes in Zeichen. Für eine Warnung müsste noch JavaScript geschrieben werden, da maxlength nur die Länge begrenzt.

multiple

definiert, dass mehrere Werte ausgewählt werden können. Nur bei type="file" und type="select" anwendbar.

pattern

definiert einen regulären Ausdruck, der das Eingabefeld validiert.

placeholder

definiert einen Platzhaltertext, der im Eingabefeld angezeigt wird. Hinweis auf erwarteten Wert.

required

definiert ein Eingabefeld, das vor dem Absenden des Formulars ausgefüllt werden muss.

formaction

definiert die URL, an die die Formulardaten gesendet werden sollen. Wird nur bei type="submit" und type="image" verwendet.

formmethod

definiert die HTTP-Methode, mit der die Formulardaten gesendet werden sollen. Wird nur bei type="submit" und type="image" verwendet.

formtarget

definiert das Ziel des Formulars. Wird nur bei type="submit" und type="image" verwendet. Es überschreibt das target Attribut des form Tags. Ist nur bei type="submit" und image anwendbar. Mögliche Werte: _self, _blank, _parent, _top.

formnovalidate

definiert, dass die Validierung des Formulars übersprungen werden soll. Überschreibt das Attribut novalidate des form Tags.
